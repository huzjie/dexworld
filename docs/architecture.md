# dexworld 架构设计

本文档描述 dexworld（多模态触觉世界模型框架）的整体架构与核心设计。

## 设计动机

传统世界模型只预测**视觉**未来。但具身智能在接触丰富（contact-rich）的灵巧操作
任务（抓取、装配、拧螺丝、揉面）里，**视觉经常被遮挡**，真正决定成败的是**触觉**
——「手摸到什么、抓得稳不稳」。ME-Dex-1.0 的核心洞见是：把触觉与视频**共同**当作
需要预测的未来世界状态，用一个统一模型联合去噪。

## 分层架构

```
┌─────────────────────────────────────────────────────┐
│  Pipeline（编排）：数据 -> 训练 -> 评测 -> 报告       │
├─────────────────────────────────────────────────────┤
│  serving / cli：HTTP 服务 + 命令行入口              │
├─────────────────────────────────────────────────────┤
│  inference：rollout / MPC 规划 / 触觉反馈预测        │
│  eval：预测精度 / 触觉重建误差 / benchmark           │
├─────────────────────────────────────────────────────┤
│  train：联合去噪损失 / 训练器 / 优化器 / 检查点      │
├─────────────────────────────────────────────────────┤
│  model：三专家 + H-Bridge + 联合去噪扩散 + 世界模型  │
│  encoders：视觉/触觉/动作专家 + 联合 tokenizer       │
├─────────────────────────────────────────────────────┤
│  data：34 区域模板 / 传感器 / 异构映射 / 仿真引擎    │
├─────────────────────────────────────────────────────┤
│  backends：Mock（可训练）/ OpenAI 兼容               │
├─────────────────────────────────────────────────────┤
│  core：types / config / constants / errors / utils   │
└─────────────────────────────────────────────────────┘
```

## 核心模块

### 1. 数据层（data）
- `TactileMap`：双手 34 区域标准模板（每手 17 区）
- `Sensor` 族：GelSight 视触觉 / 触觉阵列 / 力扭矩传感器抽象
- `HeteroMapper`：异构传感器读数 -> 34 区域标准表示
- `TactileSimEngine`：自主式触觉数据引擎（确定性接触-rich 抓取模拟器）

### 2. 编码层（encoders）
- `VisionEncoder` / `TactileEncoder` / `ActionEncoder`：三专家各自编码
- `HBridge`：跨模态共享注意力，让三模态 token 语义对齐
- `JointTokenizer`：世界状态 -> 三模态 token

### 3. 模型层（model）
- `ExpertMixture`：三专家 + 可学习门控融合
- `JointDenoiser`：联合去噪扩散器
- `NoiseSchedule`：线性 beta 噪声调度
- `DexWorldModel`：世界模型（历史 -> 未来预测 + 可训练）

### 4. 训练 / 推理 / 评测
- 联合去噪损失（视觉 + 触觉 + 动作三路 MSE）
- MPC 规划器：用世界模型预测触觉接触质量，选最优动作
- benchmark：预测精度 + 触觉重建误差

## 关键设计决策

1. **零重型依赖**：核心仅依赖 Python 标准库，`numpy` 可选（缺失自动回退纯 Python）。
2. **确定性可复现**：所有随机性基于 md5 稳定种子（非 `hash()`），跨运行一致。
3. **可训练 Mock**：无真实模型也能完整跑通闭环，并演示「误差随训练下降」。
