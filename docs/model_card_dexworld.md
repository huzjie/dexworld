# 模型卡：DexWorld 触觉世界模型

## 概览

| 项 | 值 |
|---|---|
| 名称 | DexWorld（受 ME-Dex-1.0 启发） |
| 类型 | 多模态触觉世界模型 |
| 模态 | 视觉 + 触觉 + 动作 |
| 架构 | 三专家 + H-Bridge + 联合去噪扩散 |
| 触觉模板 | 双手 34 区域 |
| 依赖 | 仅标准库（numpy 可选） |

## 训练

- 数据：自主式触觉仿真引擎生成的接触-rich 轨迹
- 损失：联合去噪（视觉 + 触觉 + 动作三路 MSE）
- 优化器：SGD / Adam / Cosine 调度

## 评测

- 视觉预测误差（越低越好）
- 触觉重建误差（越低越好）
- 接触质量评分（越高越好）

## 局限与边界

- 当前为零依赖参考实现，用于教学 / 原型验证，未在真实机器人上标定
- 传感器与物理模型为简化模型，替换为真实数据需重新训练
- OpenAI 兼容后端为可选高层语义编码，非训练主路径
